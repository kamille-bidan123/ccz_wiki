# 曹操传旧引擎 Wiki

这里集中整理 1999 年旧引擎《三国志曹操传》的文件格式、事件脚本、资源结构、编辑器设计与逆向分析资料。

本站内容来自实际游戏文件、解析工具和审计记录，重点保留可复核的格式结论、实现笔记与证据材料，方便 MOD 制作、工具开发和旧引擎研究。

## 内容导航

- **文件与格式**：游戏目录结构，以及程序、脚本、存档、图像、音视频和数据文件说明。
- **EEX 脚本**：EEX 二进制格式、命令规格、DSL 与 AST 设计。
- **编辑器**：MOD 工坊、综合修改器界面设计、实施方案和当前进度。
- **逆向分析**：旧引擎战场 AI 行动、目标选择和价值计算研究。
- **审计记录**：R 场景动作编号、人物帧与音乐编号的验证材料。
- **Godot 实现**：R 剧情播放器和场景迁移实验记录。

建议从[文件分类索引](文件与格式/文件分类索引.md)开始浏览；若关注工具实现，可直接进入[魏武·曹操传旧引擎 MOD 工坊](编辑器/魏武MOD工坊.md)。

!!! note "资料性质"
    本站内容以学习、研究和 MOD 工具开发为目的。尚未完全确认的字段和行为会在对应文档中标注。
