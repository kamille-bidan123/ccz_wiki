# 曹操传旧引擎全能 MOD 编辑器实现状态

本文对应《曹操传全能MOD编辑器方案》，记录统一工作台的真实实现边界。
格式结论仍以各分类文档为准。

## 已完成

### 项目核心

- `Project`、`CompatibilityProfile`、`DocumentStore`；
- `EntityRegistry`、`ReferenceGraph`、`ProblemStore`；
- `ResourceKey` 与可导航 `SourceRef`；
- 全项目 `ChangeSet`、撤销和重做；
- 源目录只读、working 覆盖层、事务日志、快照与发布回滚；
- 本地旧引擎 EXE 哈希和容量配置。

### 格式适配

- `Data.e5`：
  - 接受 Ls12 压缩容器和解压负载；
  - 可将 working 文件显式转换为 42079 字节解压负载，或用同版本模板恢复 Ls12 容器；
  - 两种形态均按旧引擎可直接识别的合法发布格式处理；
  - 六张业务表按物理分块解析；
  - 修改块允许未压缩写回，未修改压缩块保留原字节；
  - 重建后重新解包校验。
- `Imsg.e5`：921 条 200 字节 GBK 定长记录安全修改。
- EEX：AST 解析、命令字段修改、重建和再次解析。
- `Hexzmap.e5`：58 张地图宽高和 30 类逐格地形。
- `Pmap.e5`：74 张 100×100 二值障碍图。
- `Face.e5`、`Pmapobj.e5`、`Unit_spc/mov/atk.e5`：索引图分块替换和调色板量化。
- `Item.e5` + `Itemicon.dll`：32×32/16×16 成对写回。
- `Mgcicon.dll`：策略 32×32/16×16 图标成对写回。
- `Smlmap.e5`、`Gate.e5`：按战场调色板渲染缩略图和 0x58 动态 3×3 图块。
- `Meff.e5`、`Mcall00–08.e5`：动画步骤、A/B 图组、混合级、偏移和尾控制
  可回读修改；支持按动画调色板导入当前 A/B 图像；Meff 修改块按 Ls12
  安全重建。

### 实体联动

- 人物、兵种、物品、商店、策略、地形类别；
- S 关卡、战场地图、R 剧本、R 内场景；
- 头像、R 形象、运行时人物选择器和策略演出选择器；
- Data 人物的头像逻辑 ID 映射到 Face 物理槽；
- 递归扫描 EEX 嵌套出场列表、人物、物品、策略和 R 地图引用；
- 本地样本当前扫描结果：
  - 1,985 个实体；
  - 29,843 条引用；
  - 0 个阻断问题。

### 统一工作台

- 固定四区布局：导航、主工作区、检查器、底部工具区；
- 战役工作台按旧引擎编号配对 59 个 R 剧本与 58 个 S 关卡，汇总引用和
  问题并可双击跳转；明确不把编号配对伪装成运行时条件分支顺序；
- S 地图真实画面、地形覆盖、网格和地形修改；
- S 初始友军/敌军显示、拖动改坐标、固定槽位增删和完整出场属性编辑；
- 地图单位支持 Ctrl 多选，并可在一个 EEX 重建/撤销事务中批量覆盖方向、
  等级、最大兵力、AI 类型和隐藏状态；
- 战场右侧显示 20 槽我军/80 槽敌军逻辑容器，单位可直接在两个容器间
  拖放完成安全阵营转换；
- S 单位可查看七类旧引擎 AI 战略目标、联合参数和机器码证据说明；
- S 单位可打开物理候选评分实验器，逐项显示 `80/16/10/2` 基础档、
  目标状态、人物身份、群攻、恢复地形、战略目的地和同分键；
- 每个评分项明确标注“已核实/高可信”，不把尚未闭环的伤害公式伪装成
  精确模拟；
- Smlmap 小地图与 Gate 动态图块关卡图层；
- Gate 0x58 对象可选中、按格拖动、新增、编辑和删除；
- Hitarea/Effarea 攻击与效果范围可锚定单位预览；
- Hitarea 直接从本地范围图的逻辑格读取精确偏移；结合真实移动消耗、
  占位和敌我位置自动枚举攻击候选站位与目标；
- 策略列表按 Data.e5 的 53 兵种学习等级筛选（`00/FF` 为不可学习），
  可按策略目标类型和 Hitarea 自动枚举静态策略候选；
- 提供物理伤害、命中与策略伤害静态估算，公式来源与未覆盖的装备、
  特技和运行态分支在界面中明确标注；
- Weather 五种天气、每种四帧可叠加到战场预览；
- S 单位可在 20 槽我军表与 80 槽敌军表之间安全转换阵营；
- R 背景、障碍覆盖、人物脚底位置和障碍修改；
- R 人物命令新增、编辑、删除、拖动以及追加移动路径节点；
- 数据库字段及 Imsg 文本编辑；
- Data 商店触发人物、装备/消耗品槽、兵种物品许可、策略学习等级和
  地形适应/移动消耗定长表均可编辑；商店人物和物品槽进入引用图；
- 数据库支持多选共同字段，并作为一个事务批量修改和撤销；
- EEX 事件表双击编辑；
- EEX 事件表右键复制、删除及同一结构块内上下排序；
- 事件表提供 18 个旧引擎常用命令模板，插入前可编辑完整参数；
- 任意事件命令可用“局部变量为真/假”条件可视化包裹为 ChildBlock，
  写回后重新解析验证；
- EEX 预览 VM 支持单步、继续、偏移断点、条件人工决策和 JSON 状态快照；
- VM 已跟踪 R/S 人物、背景、音乐、天气、Gate、消息和局部变量；
- VM 能自动执行局部变量初始化/赋值，并对 `0x05` true/false 变量列表
  自动判断条件子块；含其他测试命令时仍明确暂停；
- VM 按本地 `Ekd5.exe` 机器码执行 `0x37/0x3A` 的类型 0/2 比较、
  赋值、增加、减少和上下限；运行初值可人工注入，缺失时保持未知；
- 未模拟命令会明确暂停，只能由用户人工透传，不会静默忽略；
- 头像、R/S 动作帧、物品图和策略图标预览与导入；
- Logo、Weather、Mark、Hitarea、Effarea、U_select 的 116 张固定布局
  索引图作为资源实体预览和导入；写回保持原尺寸并重新解包验证；
- 58 个 Meff 与 9 个 Mcall 作为资源实体进入导航；时间轴支持逐步、
  播放、A/B 层辅助合成、步骤字段修改、A/B 原图导入和当前帧导出；
- 引用、问题、事件和变更面板；
- 变更面板双击查看业务对象、引用数量、物理写入位置和文件字节差异；
- 全项目选择联动与引用跳转。
- 受控测试运行会先校验测试副本 `Ekd5.exe` 哈希，再保存、发布并通过
  Windows/Wine 启动；
- 测试前后读取 31 个 `Sv??d/e/s.e5s` 与 `Svcmn.e5s`，输出人物、
  战场单位、事件变量、天气和占位格等字段级 `diff.json`；
- 插件 SDK 提供 `FormatAdapter`、`EntityProvider`、`Validator`、
  `EditorProvider`、`PreviewSystem` 五个稳定注册点；
- Python 插件必须带 `plugin.json`、声明 API 版本和明确兼容配置，并由
  用户确认后启用；Star/新引擎插件不会靠版本号自动加载。
- 插件编辑器与选中实体预览可动态挂载到插件工作台；停用会撤销该插件
  的全部注册项、移出项目启用清单并重扫，但不删除插件文件。

## 后续阶段

- 策略命中、回复和装备/特技分支的进一步估算；
- 把已枚举的攻击/策略候选自动接入完整伤害、命中和 AI 总评分排序；

  注册点，彻底释放模块需重启编辑器；
