## 1. 游戏主文件

### 1.1 `SANGOKU.EXE` - 游戏可执行文件

**作用**: 游戏主程序，包含游戏核心逻辑和资源索引。

**重要数据偏移量**:
| 数据项 | 偏移量 | 说明 |
|--------|--------|------|
| 兵种数据 | 0x8AFBC | 53 个兵种的基础属性 |
| 物品数据 | - | 武器、防具、辅助物品定义 |
| 魔法数据 | - | 策略、法术定义 |

**修改方式**: 使用十六进制编辑器或专用修改工具。

---

### 1.2 `.CCZ` 文件 - 游戏资源包

**作用**: 游戏的资源压缩包，包含图片、音效、动画等资源。

**结构**:
```
CCZ 文件头
├── 文件索引表
├── 图片资源 (.BMP/.RLE)
├── 音效资源 (.WAV)
├── 音乐资源 (.MID)
└── 动画资源 (.ANI)
```

**常见 CCZ 文件**:
- `SCENE.CCZ` - 场景图片资源
- `FACE.CCZ` - 人物头像资源
- `BATTLE.CCZ` - 战斗动画资源
- `MOVIE.CCZ` - 过场动画资源

**工具**: 需要使用 CCZ 解包/打包工具进行修改。

## 2. 事件脚本文件 (.eex)

### 2.1 文件说明

**作用**: 存储游戏剧情事件的脚本文件，控制游戏的剧情流程、对话、战斗条件等。

**文件格式**: 二进制格式

**文件头**（固定 10 字节）:
```
偏移    长度    类型    说明
0x00    4       char    魔数 "EEX\0" (0x45 45 58 00)
0x04    2       bytes   固定格式标记 01 02（不解释为可变版本号）
0x06    4       bytes   固定零字节
0x0A    4       uint32  Scene 0 偏移量
...     4       uint32  Scene N 偏移量 (每个场景 4 字节)
```

旧引擎按完整 10 字节常量
`45 45 58 00 01 02 00 00 00 00` 识别文件；Scene 偏移表紧随其后。

### 2.2 场景 (Scene) 结构

每个 Scene 包含多个 Section（章节）：

```
Scene
├── Section 0
│   ├── Event 0
│   ├── Event 1
│   └── ...
├── Section 1
│   └── ...
└── ...
```

### 2.3 事件命令结构

每个事件由 命令 ID + 参数 组成：

```
事件命令
├── 命令 ID (2 字节，u16le)
├── 参数长度 (2 字节)
└── 参数数据 (变长)
    ├── 整型参数 (2 字节)
    ├── 布尔参数 (2 字节，0x0000=false, 0x0100=true)
    └── 字符串参数 (GB18030 编码，以 NUL 结束)
```
