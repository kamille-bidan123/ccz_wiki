# 音视频与辅助文本文件说明

## 范围

本类文件包括：

- `Se*.wav`
- `Se_e_*.wav`
- `Se_m_*.wav`
- `SoundTrk/*.mp3`
- `Logo.avi`
- `Press.avi`
- `open.avi`
- `end.avi`
- 以及部分辅助文本清单

## 音频文件

### `.wav`

用途：

- 战斗音效
- 对话音效
- 界面音效

样本已验证为标准 WAV：

- `RIFF`
- `PCM`
- 例如 `8-bit mono 22050Hz`

### `.mp3`

用途：

- 背景音乐

位置：

- `ccz/SoundTrk/*.mp3`

## 视频文件

### `.avi`

用途：

- 开场视频
- 按键提示
- 结尾/过场动画

样本已验证为标准 AVI。

## 辅助文本

### `README.txt`

- 原始说明文件
- 编码不是 UTF-8，需注意乱码问题

### `mp3list.txt`

- 音乐清单，由 `mp3serv.dat` 在 `WM_CREATE` 时逐行读取
- 第一行为空，对应旧 CD 的数据轨 1
- 后续第 `n` 行对应 CD 音轨 `n`，当前列出
  `SoundTrk\02-AudioTrack 02.mp3` 至 `22-AudioTrack 22.mp3`
- `Koeicda.dll` 用窗口消息 `0x1979` 把音轨号传给播放器；
  `mp3serv.dat` 以 `track - 1` 索引这一列表

## 结论

本类文件格式最清晰：

- 音频：标准 WAV/MP3
- 视频：标准 AVI
- 辅助文本：普通文本清单

`Koeicda.dll -> mp3serv.dat -> mp3list.txt -> SoundTrk/*.mp3` 的旧
CD 音轨兼容链已经由两端机器码验证。其余 WAV、MP3、AVI 均为标准媒体
容器，不需要曹操传专用解包。
