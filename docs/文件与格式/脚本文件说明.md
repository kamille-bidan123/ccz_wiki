# 脚本文件说明

## 范围

本类文件对应 `ccz` 目录中的事件脚本：

- `R_00.eex` ~ `R_58.eex`
- `S_00.eex` ~ `S_57.eex`

## 用途

- `R_*.eex`：通常对应剧情/场景段落
- `S_*.eex`：通常对应战斗/关卡事件

当前目录共有：

- `R_*.eex` 59 个
- `S_*.eex` 58 个

## 格式

`.eex` 是当前仓库里结构最明确的一类格式。

### 文件头

样本 [`ccz/R_00.eex`](https://github.com/lometsj/ccz_eex_parse/blob/master/ccz/R_00.eex) 的前 16 字节为：

```text
45 45 58 00 01 02 00 00 00 00 0E 00 00 00 01 00
```

可确认：

- `0x00-0x03`：魔数 `EEX\0`
- `0x04-0x05`：版本/格式号
- `0x06-0x09`：保留字段
- `0x0A` 之后：场景偏移表

### 结构层级

```text
EEX
├─ Header
├─ Scene Offset Table
├─ Scene[]
│  ├─ section_count (u16)
│  ├─ Section[]
│  │  ├─ section_len (u16)
│  │  ├─ test commands...
│  │  ├─ 0x0000
│  │  ├─ event_len (u16)
│  │  ├─ event commands...
│  │  └─ 0x0000
```

### 编码与字段

- 命令码：`u16` 小端
- 数值参数：多为 `u8/u16/u32`
- 字符串：`GB18030`（常规文本兼容 GBK；原版存在四字节字符）
- Section 内通常区分“条件段”和“执行段”

## 旧引擎边界与验证

本地 `Ekd5.exe` 在 `0x00410A0F` 将命令码上限固定为 `0x6B`，
`0x6C` 以上的 Star/新引擎命令不属于本地格式。仓库已完成：

- 117/117 文件解析；
- 117/117 `EEX -> AST -> EEX` 逐字节一致；
- 117/117 `EEX -> AST -> DSL -> AST -> EEX` 逐字节一致；
- 超上限命令在解析和写回阶段明确拒绝；
- 原版未使用的 `0x28` 也已依据本地主程序确定为
  `28 00 36 00 + u16le`，且在旧引擎中只是写入无消费路径的保留值；
- `0x10` 已由固定教学调用链定名为“战斗操作教学”；
- `0x6A` 已由战场高亮全局量调用链定名为“清除高亮区域”。

完整命令结构和剩余语义边界见：

- [`EEX二进制格式说明.md`](../EEX脚本/EEX二进制格式说明.md)
- [`EEX_COMMAND_SPECS草案.md`](../EEX脚本/EEX_COMMAND_SPECS草案.md)

## 结论

脚本类文件已经足够支持：

- 浏览
- 事件命令解析
- 场景/章节级编辑

文件格式、命令语义和严格保真写回已经闭环。旧引擎 `0x10`、`0x28`、
`0x6A` 均已由本地机器码定名，并在文档中与 Star 新引擎的重定义明确
隔离。
