# 脚本文件说明

## 范围

本类文件对应 `ccz` 目录中的事件脚本：

- `R_00.eex` ~ `R_58.eex`
- `S_00.eex` ~ `S_57.eex`

## 用途

- `R_*.eex`：通常对应剧情/场景段落
- `S_*.eex`：通常对应战斗/关卡事件

当前目录共有：

- `R_*.eex` 59 个
- `S_*.eex` 58 个

## 格式

`.eex`使用带类型标记的分层事件结构。

### 文件头

样本 [`ccz/R_00.eex`](https://github.com/lometsj/ccz_eex_parse/blob/master/ccz/R_00.eex) 的前 16 字节为：

```text
45 45 58 00 01 02 00 00 00 00 0E 00 00 00 01 00
```

可确认：

- `0x00-0x03`：魔数 `EEX\0`
- `0x04-0x05`：固定格式标记（未证实为可变版本号）
- `0x06-0x09`：固定零字节
- `0x0A` 之后：场景偏移表

### 物理结构概览

与主格式页使用同一套三列表记；这里省略变长区域内部字段。

```text
+--------------+----------+------------------------------------------------------+
| Offset       | Size     | Field / bytes                                        |
+--------------+----------+------------------------------------------------------+
| 0x0000       | 10 B     | Header (local original corpus)                       |
| 0x000A       | 4*N B    | Scene absolute offsets : u32le[]                     |
| scene start  | 2 B      | section_count : u16le                                |
| section      | 2 B      | section_len : u16le                                  |
| then         | variable | Top-level conditions + 00 00 + event_len             |
| then         | variable | Events / child blocks + 00 00                        |
+--------------+----------+------------------------------------------------------+
```

Section长度从长度字段之后起算，包含末尾结束标记；子事件是`01 00`＋**一条条件指令**＋执行段长度＋执行段，没有单独的条件结束标记。

详细[物理结构及边界公式](../EEX脚本/EEX二进制格式说明.md#物理结构section及长度字段)、[完整原版字节示例](../EEX脚本/EEX二进制格式说明.md#完整原版示例s_27战后处置)与[分支逻辑流程图](../EEX脚本/EEX二进制格式说明.md#逻辑流程图本段的分支)在主格式页中分别列出。

### 编码与字段

- 命令码：`u16` 小端
- 数值参数：多为 `u8/u16/u32`
- 字符串：`GB18030`（常规文本兼容 GBK；原版存在四字节字符）
- Section 内通常区分“条件段”和“执行段”

## 旧引擎边界与验证

本地 `Ekd5.exe` 在 `0x00410A0F` 将命令码上限固定为 `0x6B`，
`0x6C` 以上的 Star/新引擎命令不属于本地格式。原版命令的结构与语义如下：

- 原版未使用的 `0x28` 也已依据本地主程序确定为
  `28 00 36 00 + u16le`，且在旧引擎中只是写入无消费路径的保留值；
- `0x10` 已由固定教学调用链定名为“战斗操作教学”；
- `0x6A` 已由战场高亮全局量调用链定名为“清除高亮区域”。
