# S战场机制与调用链

本文为原版静态分析。Ekd5.exe SHA256：`c4228269bdc4d91a9db9a90c4dc9ff9a23df5333d9d0acdee98a51cba0111775`。原始函数与来源见[证据集合](S战场机制证据/retained_functions.json)。

## 一、剧情强制移动具有独立语义

原链：`43AD1C → 438308 → 43A956`。主要证据来自`battle_turns_native.json`（`ev_01f15c39ddf3d17e87ab262dace022cbc2e1bf1686f3afa6ed91edc9d8e57483`）和`script_coverage/guided_ai_native.json`；后者逐函数Evidence ID保留于抽取集合。

### 1. 预算100与FF不是一回事

`43AD1C`开始读取行动标志`0x80`。普通路径的`local_c`来自实际移动力，强制路径赋值100。但mode0/4的强制分支调用：

```text
438308(actor, current_position, FF, 02, destination.x, destination.y, 1)
若未返回1，再调用同参数但末参数改0
```

实际移动`43A956`的路线回溯也传入FF预算。因此不能将`local_c=100`直接翻译成“该特殊路径最多走100格”。调用位置和参数消费必须一起核对。

### 2. 末参数0有条件地改变穿越规则

`438308`同时读取强制标记。普通情况下，目标格只能为空或同侧；只有`末参数==0 && 强制标记!=0`时，异侧占格也能进入搜索。末参数0还使控制区扩展限制失效。

这意味着普通AI引导的第二次搜索即使忽略控制区，也不应自动获得穿过敌军的能力。搜索可穿越、最终可停留、动画如何跨占格仍是不同契约，不能合并成一个“无视阻挡”开关。

### 3. 失败返回值仍有歧义

已有`438308`伪代码中，flag02成功返回1，其他未命中路径默认返回FF；起点等于目标也落到FF。`43AD1C`强制分支第一次检查1，但第二次却检查`bVar3==0`，此时才把最终目标及保存目标改成当前位置。

两段文本之间的0/FF差异尚不能解释。原文差异有待机器指令复核；不擅自把0改为FF，也不据此宣布原版会错误移动。需要确认反编译类型/控制流、真正返回路径及调用者约束。

### 4. 普通行动标记不能照搬

`43A956`移动完成后，只有非强制路径调用`442718(actor,4)`写移动位。`43AD1C`移动后会调用`440252`；只有非强制且mode不为4，才进入普通物理/策略执行。末尾“已移动后写行动位2”同样要求非强制。

因此强制移动不等于执行普通移动后再待机。`440252`、0x80上游写入和外层事件重入尚需补全，才能确定整个生命周期。


## 二、AI候选评分与随机顺序

`43A529`把位置评分与`max(物理,策略)`相加，首先按byte绕回；随后地形分与当前格奖励使用上限255的饱和加法。最佳候选只在严格大于时更新，物理与策略同分时选物理。这三个规则会共同决定同分行为，不能统一替换为普通整数累加、全部饱和或后出现者优先。

`43A4BF`对候选格地形18..22加8，其余分支调用`43F84D(this)`取值超过10的部分；这里没有把候选坐标传给该getter。不能据此推断所有地形评分语义均已独立核实。

### 谍报的AI评分

`4395AE`的case`0x16`（策略ID22）在通过目标资格后，当源MP不超过最大MP的1/5且目标MP大于29时给20分；该case没有调用伤害估计或随机函数。指定主目标加分发生在上层。


### 无正评分分支

`4395AE`中多类玩家可施放策略没有AI正评分case。默认零分只描述该评分分支，不能直接推断策略无法施放。完整资格、遍历和随机消耗仍须按调用链区分。

伤害估计和部分状态评分会推进随机数，即使最终没有选择该策略，也不能只计算最后胜出的候选。原生主副目标消耗差异、指定目标加分及空列表规则继续以专项证据为准。

## 三、天气的随机消耗与演出触发

`449F91`（`takeover_20261013/weather_tick.json`）首先执行`47FB13(8)`，之后才检查请求阶段是否小于6。因此指定固定阶段也消耗随机数。

自然变化先以`stage+1`与抽取值比较，必要时加减1，再处理0/7边界。更新前后调用`44A1D4`取得映射后的实际天气：只有实际天气不同才停计时器999、播放`MEFF[weather+0x34]`、刷新并以500ms重启计时器。阶段改变不必然播放天气变化演出；500ms是该计时器间隔，不能当成天气特效总时长。


## 四、阵营恢复是三遍处理

`44ED93`的我友军入口在执行阶段事件且确认未结束后，对slots0..34逐人调用`43C7D6`异常恢复、`43C975`属性档位恢复；全部完成后调用`44DF61(0)`中毒，再逐人调用`43CDDD`地形/装备恢复。

这不是“人物A全套恢复完再处理B”。中间的随机状态与后续中毒资格会受顺序影响。我友军同组，友军自动阶段不能再独立扣一次毒。

`43CDDD`先计算地形及装备恢复、经验增量，若有可见变化则调用`450984`面板，然后写HP/MP，最后提交人物/武器/防具经验。计算与安装分离；完整表现期间的可见状态还需要逐路径比较。
